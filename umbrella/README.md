# oas2moon

Umbrella entry point for the complete `oas2moon` MoonBit client SDK generator suite.

This package depends on the four published implementation modules:

- `Atman-Angle/oas2moon_frontend`
- `Atman-Angle/oas2moon_core`
- `Atman-Angle/oas2moon_codegen`
- `Atman-Angle/oas2moon_runtime`

The generator command-line entry point is currently installed from the source repository.

Repository: <https://github.com/Atman-Angle/oas2moon>
